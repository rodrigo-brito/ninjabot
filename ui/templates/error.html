How to fix it:

  • No network? The bundle is downloaded once from GitHub Releases and cached locally. Connect and restart, or run once on a machine with internet.
  • Development build? Build the dashboard locally (cd web && bun install && bun run build) and start the bot with {{.EnvDir}}=$PWD/web/dist or ui.WithUIDir("web/dist").
  • Pin a version with {{.EnvVersion}}=vX.Y.Z or ui.WithUIVersion("vX.Y.Z").

The JSON API keeps working: /api/pairs, /api/{pair}/snapshot, /api/events.
